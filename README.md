# Paradise Nursery

Paradise Nursery is an online plant shop application where users can browse different houseplants, view plant details, and add plants to a shopping cart.

## Project Description

This project is a dynamic shopping cart application developed for Paradise Nursery. It allows users to:

- Browse houseplants by category
- View plant names, descriptions, images, and prices
- Add plants to the shopping cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total cost of the shopping cart
- Continue shopping from the cart page

## Technologies Used

- React
- Redux
- JavaScript
- HTML
- CSS
